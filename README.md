# Bits to Pixels Lab

An interactive lab that shows how computers represent text, colours and images as numbers. Everything runs in the browser.

## Experiments

The page has four hands-on experiments:

1. **Text → Binary:** Type text and see each character as its numeric code and bits.
2. **RGB → Pixel:** Adjust red, green and blue values and see the colour and its binary form change.
3. **Procedural Art:** Draw simple scenes, such as a watch, a car, or an animal, from code instead of image files.
4. **Image → Pixels:** Upload an image and inspect its pixels as RGB values and binary bits.

## Running it

No build step or server is needed. Open `index.html` in a browser.

## Theme

The page uses light colours by default. If your browser or operating system is set to dark mode, the page switches to a dark theme automatically. Colours are defined as CSS variables at the top of the stylesheet in `index.html`.

## Files

- `index.html`: the whole app (markup, styles and scripts in one file)
